## 状态标记

- `已验证`：已有命令输出、提交或云端响应可核验。
- `进行中`：已开始但未满足验收条件。
- `待人工执行`：必须由团队成员登录华为云、CodeArts 或完成拍摄/录屏。
- `阻塞`：依赖外部资源、凭据或赛事规则确认。

严禁把 Codex、人工编写或历史代码描述为 CodeArts 生成。截图不得包含密钥、Token、验证码、精确鸟类坐标、个人邮箱或本机绝对路径。
