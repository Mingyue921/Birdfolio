# ICT 参赛版本验收清单

## P0：必须通过

### Web 闭环

- [ ] 快捷登录获得隔离的临时账号，不共享其他体验者数据。
- [ ] 浏览器拒绝损坏文件和非图片，超大图压缩后上传。
- [ ] AI 返回最多 3 个真实候选；无 Key/超时不生成模拟结果。
- [ ] 低置信度有清晰提示，未确认时观察数不变化。
- [ ] 确认后观察列表与统计同步更新。
- [ ] 刷新页面可恢复有效会话；刷新 Token 失败则安全退出。

### 云与安全

- [ ] 公网 HTTPS 无证书警告，HTTP 自动跳转 HTTPS。
- [ ] 公网只暴露 443；数据库和 Redis 不可公网直连。
- [ ] `/health/live` 返回 200。
- [ ] `/health/ready` 真实检查 RDS、DCS、OBS，故障时返回 503。
- [ ] OBS 私有，匿名访问失败。
- [ ] 容器重启后观察仍存在。
- [ ] 比赛账号过期后账号、观察、识别请求和相关媒体被清理。
- [ ] 仓库扫描无 Key、Token、数据库、用户照片、证书或签名材料。
- [ ] 社区与敏感物种位置不返回精确坐标。

### 工程与证据

- [ ] 服务端全部测试通过，PostgreSQL 集成测试不跳过。
- [ ] Web 单测、构建和 Playwright 核心流程通过。
- [ ] Docker 镜像可从空环境启动。
- [ ] 数据库迁移重复执行幂等。
- [ ] 上一版本镜像回滚演练成功。
- [ ] CodeArts 五类证据均有真实提示词、提交和结果。
- [ ] Apache-2.0 与第三方素材清单完整。

## P1：应通过

- [ ] 桌面、平板、手机宽度均无横向溢出。
- [ ] 30 秒内返回候选或明确错误。
- [ ] MaaS 401、429、5xx、非法 JSON 映射为可理解状态。
- [ ] Redis 限流失败关闭；缓存失败允许跳过缓存调用模型。
- [ ] AI 缓存命中和未命中业务结果一致。
- [ ] 手机热点和校园网络各演示一次。
- [ ] 三位成员均可独立完成三分钟演示。
