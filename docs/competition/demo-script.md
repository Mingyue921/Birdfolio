# 三分钟演示脚本

状态：脚本草案；需在公网环境按秒排练。

## 固定演示（180 秒）

| 时间 | 操作 | 讲解重点 |
|---|---|---|
| 0:00–0:20 | 标题页 + 一句话定位 | 普通人“看见但认不出、记录分散”，Birdfolio 用 AI 候选和人工确认连接识别与记录。 |
| 0:20–0:35 | 打开公网 Web，快捷进入临时账号 | 临时账号隔离、24 小时过期，演示入口不等于正式商业登录。 |
| 0:35–0:55 | 上传固定授权鸟图，填写日期/粗粒度地点/栖息地 | 浏览器压缩并移除 EXIF，原图不公开。 |
| 0:55–1:25 | 展示 MaaS Top 3 | 讲清模型分数、上下文分数、最终分数、辨识特征与低置信度处理。 |
| 1:25–1:45 | 人工确认 | AI 只缩小范围，用户确认后才创建观察。 |
| 1:45–2:05 | 观察列表与仪表盘 | 数据写入 RDS，统计即时更新；敏感位置只展示模糊信息。 |
| 2:05–2:25 | HarmonyOS 录屏/真机片段 | 展示地图、离线记录和手账作为多端延展，不现场依赖设备网络。 |
| 2:25–2:45 | 架构图 | ECS、RDS、DCS、OBS、MaaS 各自承担真实职责。 |
| 2:45–3:00 | CodeArts 证据与结尾 | 展示开发、修复、构建、部署的真实记录；强调自然教育价值。 |

## 演示前 10 分钟检查

- [ ] 公网 HTTPS、live/ready 均正常。
- [ ] 固定测试图片本地可用且授权记录完整。
- [ ] 新建一次临时会话，确认配额未耗尽。
- [ ] 预热 MaaS（不把缓存结果冒充实时调用）。
- [ ] HarmonyOS 备用录屏离线可播放。
- [ ] 架构图和 CodeArts 截图均已脱敏。

## 失败降级

- AI 超时：展示明确错误，再播放同一版本提前录制的真实成功请求；说明当前云服务状态，不伪造现场结果。
- 公网故障：切换只读演示录屏，同时展示最近一次流水线和健康检查时间。
- HarmonyOS 设备故障：只播放录屏，不临时重装或清数据。
- 禁止使用硬编码候选、修改数据库制造统计或把 Demo 模式称为真实识别。
