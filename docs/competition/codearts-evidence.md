# CodeArts 真实证据台账

状态：待人工执行。当前未登记任何 CodeArts 产出。

## 证据规则

每条记录必须同时具备提示词、结果、提交和验证。截图只证明操作过程，不能替代测试结果。已有 Codex 或人工代码不得补写成 CodeArts 产出。

截图存放于 `docs/competition/evidence/<date>/<member>/`，文件名使用 `01-requirement.png` 等无敏感信息的名称。提交前检查邮箱、密钥、Token、验证码、精确坐标和本机路径。

## 单条记录模板

### E-YYYYMMDD-01 — 任务名称

- 日期：`YYYY-MM-DD HH:mm +08:00`
- 成员：`A / B / C`
- 类别：`需求理解 / 代码生成 / 问题修复 / 项目构建 / 部署上线`
- 工作区与分支：`...`
- 完整提示词：

  ```text
  在此原样粘贴，不包含密钥或个人数据。
  ```

- CodeArts 输出摘要：`客观描述建议或改动，不夸大。`
- 关联提交：`<完整 commit hash>`
- CodeArts 实际修改文件：`...`
- 人工修改：`逐项说明；若无则写“无”。`
- 截图相对路径：`evidence/YYYY-MM-DD/member/xx.png`
- 验证命令：`...`
- 验证结果：`通过/失败；测试数量或错误摘要。`
- 复核人：`另一名成员`

## 证据复核

- [ ] 时间顺序与 Git 提交时间合理。
- [ ] 提示词完整且没有事后改写。
- [ ] 提交确实包含所述改动。
- [ ] `codearts:` 前缀只用于真实 CodeArts 参与的提交。
- [ ] 截图无遮挡关键信息且不泄密。
- [ ] 构建/部署结果可通过日志或 URL 二次核验。
