## 4. 当前用户入口

- **AI 授权与撤回**：设置页“AI 图片识别”；撤回只阻止后续上传，不自动删除历史数据。
- **账号数据导出**：设置页已登录状态下导出；当前只覆盖云端观察、帖子和评论。
- **账号注销**：设置页“删除云端账号”；删除云端关联数据但保留设备本地数据，用户表仍软删除保留部分字段。
- **定位控制**：观察编辑页“使用当前位置”触发系统权限；拒绝后可保存无坐标记录。
- **社区举报**：服务端已有帖子举报 API，但当前客户端没有可验证的举报入口，属于正式发布前必须完成。
- **诊断控制**：本地保存诊断开关，默认关闭；未发现诊断上传实现，也未发现开关控制全部 `hilog` 输出。

## 5. 正式发布前必须完成

1. 从 Release HAP 提取最终权限和 SDK 清单，删除不必要的 `ohos.permission.LOCATION` 或证明其必要性。
2. 移除生产日志中的精确坐标、地点名、文件 URI/路径和令牌相关信息，并验证诊断开关的真实作用。
3. 完成 HTTPS、正式邮件网关、生产部署、访问控制、备份和自动清理。
4. 为 AI 媒体、识别记录、账号软删除字段、日志和备份实现经批准的保留/删除规则。
5. 完成客户端社区举报入口、管理员处置后台和申诉流程。
6. 实现敏感鸟类位置强制保护；当前 `fuzzyLocation` 只是一项标记。
7. 确认所有第三方 SDK/服务的数据字段、处理地区、共享目的和隐私政策，并与 AppGallery 表单保持一致。
8. 对隐私政策、系统权限弹窗、应用内同意文案和 AppGallery 数据安全表逐项做一致性验收。
