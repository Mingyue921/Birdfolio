## 1. 社区定位

Birdfolio 社区用于分享观鸟记录、照片和手账，并进行评论、点赞和收藏。社区不鼓励以追逐、诱拍、闯入保护区或暴露敏感位置换取互动。

当前已实现帖子、评论、点赞、收藏、举报和屏蔽基础接口，以及“所有人/仅自己”可见范围。关注关系、管理员审核后台、举报处置界面、内容申诉和分级处罚均为`待开发`。

## 2. 鼓励的内容

- 尊重鸟类和栖息地的真实观察记录；
- 清楚区分亲眼观察、AI 候选、人工确认和引用资料；
- 分享不会导致干扰或盗猎风险的自然教育信息；
- 为照片、图表和引用资料保留作者及来源；
- 以友善、可核查的方式纠正可能的物种误判。

## 3. 禁止的内容和行为

不得发布或实施：

- 违法、欺诈、威胁、骚扰、仇恨、色情、血腥暴力或侵犯他人权益的内容；
- 未经许可披露他人邮箱、精确住址、行踪、肖像或其他个人信息；
- 盗用照片、移除水印、伪造作者信息或侵犯知识产权；
- 冒充他人、批量刷赞刷评、广告垃圾、恶意链接或自动化滥用；
- 故意伪造观察、篡改证据，或把 AI 候选宣称为专家确认结果；
- 捕捉、买卖、投毒、伤害鸟类及破坏鸟巢、鸟蛋或栖息地的内容；
- 诱导他人投喂、诱拍、播放鸟鸣、围堵、追逐或进入封闭区域；
- 发布敏感鸟类、巢址、繁殖地、夜栖地或盗猎目标的精确位置、路线、地标组合和未清除定位元数据；
- 为非法捕猎、交易或骚扰提供教程、工具、联系方式或定位协助。

## 4. 位置发布要求

社区帖子当前不上传经纬度字段，但会上传用户填写的地点名称，照片和正文也可能泄露位置。用户发布前应：

- 将敏感地点降为城市、区县或更粗粒度描述；
- 删除路牌、建筑、路线、拍摄参数等可反向定位线索；
- 对敏感观察延迟发布，避免实时聚集；
- 不依赖“模糊位置”界面标记，因为当前尚未实现自动坐标模糊。

具体规则见《敏感鸟类位置保护规则》。

## 5. 举报与屏蔽

服务端已提供举报帖子和屏蔽用户的基础 API，但当前客户端没有可验证的用户举报或屏蔽入口。用户可见入口、解除屏蔽界面和完整双向隔离规则均属于`待开发`。屏蔽 API 生效后，会使发起屏蔽的用户在帖子列表中不再看到被屏蔽用户的帖子。

通过 API 提交的举报当前只会生成状态为 `open` 的记录，不代表已有管理员受理或完成处置。公开开放社区前，必须配置客户端举报入口、管理员后台、人员、证据留存、处置标准、紧急敏感位置下架和申诉流程。

## 6. 处置原则（待运营落地）

正式运营后，可根据严重程度采取提醒、限制传播、删除内容、限制功能、暂停或终止账号，并在法律要求时配合主管机关。涉及敏感鸟类实时位置、盗猎交易或人身危险的内容应优先处理。

上述处置流程、通知方式、时限和申诉机制当前均为`待开发/待运营配置`，不应在功能完成前对外承诺具体响应时间。
