## 当前事实边界

- 应用以本地存储为主；游客可使用观察记录、地图、图鉴和手账等本地能力。
- 邮箱验证码账号、云端观察同步、账号数据导出和云端账号删除已有基础接口，但真实邮件网关、公网生产部署、备份恢复和大规模跨设备验证尚未完成。
- AI 图片识别需要登录并单独同意上传；图片先到 Birdfolio 后端，再由后端转发至配置的 OpenAI-compatible 视觉服务。AI 只返回候选，用户确认后才形成识别确认或观察记录。
- 社区已有帖子、评论、点赞、收藏、举报和屏蔽基础接口；管理员审核后台、举报处理和申诉流程待开发。
- 当前社区帖子结构不包含经纬度，只包含用户填写的地点名称；观察记录可保存精确坐标。`fuzzyLocation` 当前是标记字段，尚未实现坐标模糊算法或区县级转换。
- 诊断信息开关目前只有本地设置存储，未发现实际诊断数据上传实现。
